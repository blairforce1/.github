# Security policy

## Reporting a vulnerability

Email **git@blairforce1.com** with the subject `security: <repository>`.

Do not open an issue. Most repositories under this account are private, and
GitHub's private vulnerability reporting is only offered on public
repositories, so email is the one route that works for all of them.

Include the repository, the commit or tag, steps to reproduce, and the impact
you believe it has.

## What to expect

- Acknowledgement within five working days.
- For a confirmed report, a fix or a written decision not to fix within 30
  days of acknowledgement.
- Credit in the fix's release note if you want it.

## Scope

Every repository owned by blairforce1 that does not ship its own
`SECURITY.md`. A repository's own file takes precedence over this one.

## Supported versions

Only the default branch and the latest tagged release of each repository
receive fixes.
